#  Examen Final Móvil – Flutter + Firebase

Aplicación móvil desarrollada en **Flutter**, conectada a **Firebase Authentication** y una **API REST**, como parte del *Proyecto Final de Ingeniería en Informática*.

Permite la gestión completa (CRUD) de **productos**, **categorías** y **proveedores**, con autenticación segura y verificación de correo electrónico.

---

##  Funcionalidades principales

 **Inicio de sesión y registro de usuarios**
- Permite ingresar con correo y contraseña.
- Se puede crear una nueva cuenta (Firebase enviará un correo de verificación).
- Recuperación de contraseña disponible.

 **Gestión de productos**
- CRUD completo (crear, editar, eliminar, listar).
- Cada producto incluye nombre, precio, descripción e imagen.
- Al tocar un producto se puede editar directamente.

 **Gestión de categorías**
- CRUD completo (crear, editar, eliminar, listar).
- Indica si la categoría está activa o inactiva.

 **Gestión de proveedores**
- CRUD completo (crear, editar, eliminar, listar).
- Cada proveedor incluye nombre, teléfono y correo electrónico.
- Al tocar un proveedor se puede editar su información.

 **Diseño moderno y responsivo**
- Interfaz clara, intuitiva y coherente en todas las pantallas.
- Uso de **Material 3**, widgets reutilizables y arquitectura ordenada.

---
